# Biblioteca de Libros

## Descripción

Este es un proyecto de gestión de libros que permite a los usuarios agregar, editar, eliminar y visualizar libros en una biblioteca virtual. También incluye un sistema de inicio de sesión, donde solo los usuarios registrados pueden acceder a las funciones de la aplicación.

## Lenguajes, Frameworks y Tecnologías Usadas

- **Frontend**:

  - [React](https://reactjs.org/) - Biblioteca de JavaScript para construir interfaces de usuario.
  - [TypeScript](https://www.typescriptlang.org/) - Superset de JavaScript que agrega tipado estático.
  - [React Router](https://reactrouter.com/) - Biblioteca para manejar el enrutamiento en aplicaciones React.

- **Backend**:

  - [Node.js](https://nodejs.org/) - Entorno de ejecución para JavaScript en el lado del servidor.
  - [Express](https://expressjs.com/) - Framework web para Node.js para construir API RESTful.
  - [CORS](https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS) - Middleware para habilitar CORS.
  - [Body-Parser](https://www.npmjs.com/package/body-parser) - Middleware para analizar cuerpos de solicitudes entrantes.

- **Almacenamiento**:
  - JSON como formato para almacenar libros en un archivo (`books.json`).
